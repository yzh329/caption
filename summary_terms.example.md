# Summary Prompt Terms Example
#
# Copy this file to summary_terms.md and edit it for your own meetings.
# summary_terms.md is intentionally ignored by Git because it may contain
# private names, customer names, project names, and internal product terms.
#
# Lines starting with # are ignored by the summarizer.

# Examples:
# - Jane Doe: person name. Preserve this spelling when context fits.
# - Project Atlas: project name. Preserve English spelling.
# - API Gateway: service name. Preserve acronym/capitalization.
# - customer_id: database column. Preserve exact lowercase underscore spelling.
# - Translation preference: keep product names, APIs, repos, and acronyms in English.
# - Uncertainty rule: if the transcript is unclear, write [unclear: original phrase] instead of guessing.
